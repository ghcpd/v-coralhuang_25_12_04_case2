# Advanced TODO Tag System

This workspace implements an advanced tag system for a simple in-memory TODO app.

- Persistent storage via SQLite
- Structured tags with metadata and co-occurrence
- Mini DSL for tag queries
- Plugin hooks and sample plugin
- Backwards-compatible API via `todo_advanced.py`

Run tests: use `pytest` or the helper `run_tests.ps1` / `run_tests.sh`.
